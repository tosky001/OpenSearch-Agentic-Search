# Self-Evolving Agents

[English](README.md) | **简体中文**

让 Agent 在任务执行中递归改进，在跨任务经验中积累技能，在多 Agent 协作中验证答案。

Self-Evolving Agents 是一个围绕 **任务内递归自我改进、跨任务技能积累、跨 Agent 验证与集成** 设计的三层自演进框架。它将执行轨迹、验证结果和可复用技能连接起来，探索 Agent 如何利用实际任务中的反馈，持续改进问题求解过程。

> **项目状态：** 当前仓库先行公开方案介绍与架构图，相关实现代码将在后续开源并逐步加入。本阶段暂不提供可运行代码和安装说明。

## 为什么需要自演进

复杂任务往往需要多轮推理、工具调用和结果检查。一次执行中的错误、修正过程和有效做法，如果能够被记录、提炼并复用，就能为后续任务提供经验。同一问题也可能产生多个候选答案，需要进一步验证和集成。

本框架从三个层次处理这些问题：

- **任务内：** 通过递归自我改进，诊断执行轨迹、验证答案并改进执行上下文。
- **跨任务：** 从执行轨迹中挖掘共性模式，提炼可复用的技能或工具。
- **跨 Agent：** 对不同 Agent 的候选答案开展多视角验证，再进行异构集成。

这里的“自演进”主要体现为执行策略的改进、技能的积累与复用，以及候选答案的验证与集成。

## 方案架构

![Self-Evolving Agents 三层自演进架构](architecture.png)

### A. 递归自我改进

**Recursive Self-Improvement · Intra-Trajectory**

任务分发给 Agent A、Agent B、Agent C 等多个 Agent。每个 Agent 独立运行递归自我改进循环，验证通过的候选答案随后汇入共同的候选答案池。

架构图上方展示多个 Agent 的并行路径，下方单独展开它们共同采用的内部机制：

1. **任务执行：** 执行 Agent 完成任务，产生执行轨迹和候选答案。
2. **评估验证：** 评估 Agent 对轨迹进行诊断，并验证答案。
3. **上下文改进：** 验证未通过且仍有可用执行次数时，总结错误原因并加载到执行 Agent 的上下文中，再使用改进后的上下文重新执行。

答案验证通过或达到最大执行次数时，循环终止。达到次数上限不代表答案通过验证。

### B. 经验驱动的 AutoSkill 增强

**Experience-Driven AutoSkill Augmentation · Cross-Task**

这一层将多个任务的执行经验转化为可复用能力。AutoSkill 在这里指从执行轨迹中提炼、验证并积累技能的机制。

| 环节 | 作用 |
| --- | --- |
| 执行轨迹汇集与聚类 | 汇集任务执行记录，将相似轨迹归类，为模式分析提供输入。 |
| 共性模式挖掘 | 识别不同任务中重复出现的问题、处理步骤或有效做法。 |
| 技能 / 工具提炼 | 将可复用的经验整理为技能或工具。 |
| 跨任务验证 | 在不同任务中检验所提炼能力的适用性。 |
| 技能库 | 沉淀经过验证的技能，供后续任务复用。 |

图中的两条虚线连接了任务执行与技能积累：

- **运行反馈（Runtime Feedback）：** 将执行步骤、工具调用、报错、反思和验证结果等轨迹信息送入汇集与聚类流程。
- **技能复用（Skill Reuse）：** 将技能库中积累的能力用于后续任务执行。

这一过程使单次任务中的经验有机会在更多任务中发挥作用。

### C. 跨 Agent 协作：验证与异构集成

**Cross-Agent · Verification & Heterogeneous Ensemble**

不同 Agent 产生的候选答案首先进入候选答案池，再按不同组合构成多个验证视角。架构图以三个视角为例：

| 验证视角 | 候选答案组合 | 验证结果 |
| --- | --- | --- |
| 视角 1 | A、B、C | V₁ |
| 视角 2 | A、C、D | V₂ |
| 视角 3 | B、D、E | V₃ |

各视角分别验证候选答案，随后将 V₁、V₂、V₃ 送入第二阶段的异构集成，形成最终答案。图中的组合用于说明机制，具体候选数量、视角构建方式及集成策略以未来公开的实现为准。

## 一次任务如何参与自演进

1. **执行与改进：** 任务进入执行层，各 Agent 独立运行递归自我改进循环，验证通过的答案进入候选答案池。
2. **验证与集成：** 候选答案进入答案池，经过多视角验证和异构集成后输出最终答案。
3. **经验积累：** 执行轨迹作为运行反馈进入跨任务流程，经模式挖掘、技能提炼和跨任务验证后沉淀到技能库。
4. **后续复用：** 新任务使用已有技能，并继续产生新的执行反馈。
